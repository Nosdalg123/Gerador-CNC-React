Trazer dados da versão antiga

Abra a versão antiga no navegador e endereço que contém seus dados. Pressione F12 e abra Console. Copie o código abaixo e execute naquele Console. Ele baixa um JSON local sem alterar os dados existentes.

Esta página auxiliar apenas apresenta o código: seu armazenamento pertence a outra origem e não contém automaticamente os dados antigos.

const dados = {localStorage: {}};
for (let i=0;i<localStorage.length;i++) {
  const k=localStorage.key(i);
  if ((k.startsWith('cnc.')||k==='cnc_dxf_rascunhos_v1')) dados.localStorage[k]=localStorage.getItem(k);
}
const a=document.createElement('a');
a.href=URL.createObjectURL(new Blob([JSON.stringify(dados,null,2)],{type:'application/json'}));
a.download='cnc-dados-antigos.json'; a.click();

Depois, no programa React, abra Dados e backup → Escolher arquivo JSON → Mesclar e manter dados existentes.
